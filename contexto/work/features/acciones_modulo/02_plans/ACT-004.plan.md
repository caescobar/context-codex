### A1. Repo Standards (Backend)
- FastEndpoints usa rutas `/api/v1/*`, `Tags("Actions")` y `Policies(PermissionClaims.Actions.*)`.
- CQRS-lite consistente: `ICommand<Result<T>>` + `ICommandHandler<,>` en archivos `*CommandHandler.cs` y `*QueryHandler.cs`.
- Mapeo request->command con Mapster (`Adapt<>()`) en endpoints de escritura.
- Envelope `Result<T>` y salida HTTP con `Send.OkAsync` / `Send.ErrorsAsync`.
- Acceso a DB por `IApplicationDbContext`; consultas y escrituras via EF Core + `SaveChangesAsync`.

### A2. Repo Standards (DB)
- El repo tiene SQL en dos ubicaciones (`telemetric-api/scripts/` y `telemetric-api/src/Telemetric.Api/Database/Migrations/`); para este requirement esta cerrada la ruta en `telemetric-api/scripts/*.sql`.
- `RuleInstance` ya existe con `OverridesJson` y unicidad `(DeviceId, RuleTemplateVersionId)`.
- Soft-delete y auditoria (`IsActive`, `IsDeleted`, `CreatedAt`, `UpdatedAt`) estan presentes en SQL y EF.
- Semantica de duplicado esta definida con indice unico no filtrado para `RuleInstance`.

### A3. Story Fit Check
- Necesidades ACT-004 (spec/storypack): asignacion masiva template-version -> devices, flujo desde Device Detail (local/reusable), bloqueo de duplicados y whitelist de overrides v1.
- Ya existe base reutilizable:
  - BE templates/runs: `telemetric-api/src/Telemetric.Api/Features/Actions/Templates/*`, `telemetric-api/src/Telemetric.Api/Features/Actions/ResolveManual/*`
  - FE actions: `telemetric-front/src/features/actions/*`
  - Modelo DB: `RuleTemplateVersion`, `RuleInstance` y constraint unico.
- Gaps pendientes (esperables para implementacion):
  - endpoint(s) de asignacion masiva,
  - endpoint(s) create-from-device local/reusable,
  - validacion de overrides v1 (`threshold`, `email.recipients`),
  - UI de asignacion y feedback de duplicado.

### A4. Guardrails Confirmation
- Reuse-first obligatorio para endpoints (discover -> equivalence -> reuse -> only-if-missing).
- Mantener `telemetric-api/scripts/*.sql` como ruta SQL para este requirement.
- No relajar regla de duplicado `(DeviceId, RuleTemplateVersionId)` ni semantica de soft-delete vigente.
- UI en espanol; nombres tecnicos/contratos en ingles.
- QA pack solo en rutas canonicas:
  - `contexto/work/features/acciones_modulo/04_test/ACT-004/phase-{phase_id}/`
